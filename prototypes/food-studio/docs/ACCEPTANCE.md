## 交互

- [ ] Home 进入 Food；可返回入口。
- [ ] 输入 Chinese Soup，出现正确结果；详情显示食品与地点。
- [ ] 类型与 Open now 组合筛选可用。
- [ ] Opening hours 展开/收起不跳详情。
- [ ] 进入详情再返回，保留搜索、类型、营业筛选、展开和滚动位置。
- [ ] 详情 → 地图 → Back → 详情；返回结果保持来源。
- [ ] 无结果时 Clear search 与 Reset filters 各自只清对应条件。
- [ ] 未知营业信息与 Closed 文案不同。
- [ ] 外部服务提示可退出，Escape 与键盘焦点可用；没有真实提交。
