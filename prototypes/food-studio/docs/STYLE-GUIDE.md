# Fresh Campus / 视觉与组件规范 v0.2

适用：Food 完整交互原型、报告插图、PPT 和团队可复用组件。2026-10-23 用户已确认清爽校园方向并通过完整包本地验收。本规范是学生设计提案，不代表 PolyU 官方品牌。

## 1. 颜色与使用

唯一颜色源是 `tokens.json`。不要分别在界面、插图、PPT 中另建配色。

| 变量 | 色值 | 用法 |
| --- | --- | --- |
| ink | #182F46 | 深蓝：标题、正文、亮绿按钮文字 |
| muted | #526579 | 辅助信息与图注 |
| canvas | #F6F7F2 | 米白：页面、PPT 封面与结尾 |
| paper | #FFFFFF | 内容面与报告底色 |
| accent | #C4EF71 | 明亮绿：选中按钮、重点标记、插画填充 |
| accentSoft | #ECF6DD | 浅绿：选中背景、详情标题区、PPT 图片衬底 |
| success | #286144 | 深绿：链接、键盘焦点、营业中文字 |
| line | #DCE3DA | 轻分隔线 |
| closed / closedSoft | #725339 / #F5EDE4 | Closed 状态与浅底 |
| warning / warningSoft | #885B13 / #FAF0DA | Hours unavailable 状态与浅底 |

明亮绿上用深蓝字，不用白字。禁止将亮绿用于小号正文。状态既有颜色也有文字，未知营业时间不等于关闭。

## 2. 字体与版式

- 英文 Arial，中文 Microsoft YaHei，后备系统无衬线；在目标设备确认替代字体与换行。
- 手机主标题 32–35px，分节 20–25px，卡片名称 16px，营业摘要 14px，位置/操作 12px。DEMO 等非关键注记 9–11px，不承担任务信息。
- PPT 1280×720（16:9）；标题通常 52px（39pt），封面 76px（57pt），正文 29px（约22pt），辅助说明至少20px。网页缩略预览不作为正文字号依据。
- 间距 4/8/12/16/24/32/48/64。大区域通过留白和分隔线区分，不层层加框。
- 容器圆角20px、控件12px；筛选标签用胶囊形。餐饮列表用行间分隔线，避免嵌套卡片。

## 3. 界面组件与行为

Food 标题旁使用小型餐碗插画；首页使用咖啡插画。插画不占用搜索和关键信息的位置。

餐饮条目顺序：名称/分类 → 位置 → 带文字的营业状态 → 今日营业摘要 → Opening hours / View details。保留商户原品牌缩略图作识别，不能用装饰餐碗替代商户身份。

Opening hours 独立展开时间表；View details 和标题进入详情。返回恢复搜索、类型、营业筛选、展开状态和滚动位置。地图返回详情；标签结果返回来源详情。

搜索与类型、Open now 同时生效。Clear search 只清搜索词，Reset filters 只清筛选。错误输入必须转义；空状态提供可执行恢复。

点击区域至少44px，键盘焦点3px深绿。弹窗限制焦点、支持 Escape，关闭后回到触发按钮；背景不可交互。外部订餐只有模拟提示，不提交真实订单。

## 4. 插图与报告图

- 餐碗与咖啡使用已批准的简洁深蓝轮廓、亮绿填色、白色留空，保持原比例；SVG 源文件在 assets/，PNG 导出在 exports/。
- 这两张图是自绘装饰，不是真实餐厅照片，也不承载商户或地图信息。
- 报告图1200×760，白底两栏，保留 BEFORE/AFTER 标签、历史来源、日期与“设计提案/待验证”说明。
- A/B 标注用亮绿底深蓝字，分隔线少而清晰。旧图保持原样，不能因统一视觉而重绘原应用证据。
- `figure-01.png`：营业时间与详情入口；`figure-02.png`：搜索结果区分信息。

## 5. PPT

封面沿用获认可的餐碗图与深蓝大标题；正文白底，关键重点用亮绿短线，截图完整保留比例；最后一页米白底列出评估计划。

标题、正文、页码与色块可以直接在 PowerPoint/WPS 中编辑。截图和装饰插图以图片嵌入；单个按钮和截图内文字需回到原型修改后重新导出。SVG 源文件另行提供。

网页展示六张 PPT 构建时生成的逐页图，与下载的 PPTX 为同一版。不保留第二套手工模拟的幻灯片排版。

每页讲一个主题；不编造测试统计。来源与演示限制写入备注，影响理解的说明保留在页面中。

## 6. 修改与发布顺序

修改 tokens.json → 运行 tools/sync-tokens.mjs（同步CSS/JS/SVG）→ 修改原型 → 检查界面 → 重新导出两张界面图与两张报告图 → 运行 tools/build-deck.mjs → 检查六页 → 更新本地包。

布局调整在 styles.css（基础）和 fresh.css（新版视觉）中完成。不要直接修改导出的 PNG。构建 PPT 使用新的输出文件名，完成后更新 app.js 中的下载路径。
