# Map — Maze 测试结果（E，2026-11-10）

原型：Figma Map 改版（F0–F5 + 两个起点浮层）。
工具：Maze Prototype Test，非主持、远程、参与者自备设备。
导出：`polyulife-map-test_report_*.pdf`（2026-11-10），本文件是该报告的数据摘要。

## 方法与样本

- 5 名非组员参与，按顺序完成 4 个任务；1 人在任务 1 后退出，因此任务 2–4 各有 4 份回应。
- 每个任务固定起点画面与预期终点画面，由 Maze 自动判定成功/放弃。
- Maze 记录每人每任务的完成率、放弃率、误点数、用时；结尾 1 道评分题 + 1 道开放题。
- 告知参与者这是学生原型，没有"错误答案"。

## 热力图读出的问题

- **F0**：搜索框是最热的位置，比建筑卡片还热 → 第一反应是搜索，而搜索框当时不可用。
- **F2**：`Water stations` chip 被点中（任务要求的第一步），但底部面板的拖拽把手几乎没有点击
  → 折叠状态看不出可以展开，与 50% 放弃和原话互相印证。
- **F2 / F2b**：`Start: Lift 2, 3/F` chip 是屏幕上被点最多的死区；地图上的设施图标与图例
  同样被点击但没有响应。
- **F4**：`Take me there` 被准确点击，说明主行动位置正确。

## 据此做的修改（iteration）

1. 折叠面板末尾加 "3 more on this floor"，并让列表行可点。
2. 起点 chip 加重边框并可点，打开起点选择浮层。
3. P/F 空状态加 3F 角标与唯一主按钮 "Show me 3/F"。
4. 无去向的楼层按钮改为灰态；移除无意义的 "Clear"。
5. 搜索框改为可见的不可用状态（"coming soon"）。
