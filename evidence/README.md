# 界面与评估证据

本目录保存适合团队共享、可复查的脱敏证据。[2026-09-28 全应用走查](2026-09-28-full-audit/) 已包含 Room 和 More 部分流程的真实截图及校验清单；实际动作、证据引用与未完成范围见 [观察台账](../docs/polyulife/README.md)。目录名称表示研究目标，不表示全应用已验证。

## 一条流程怎样记录

实际取证时创建日期与任务目录，例如 `evidence/2026-09-28-room-enquiry/`，包含一份 `walkthrough.md` 和必要的脱敏截图。避免先堆积空功能目录。

`walkthrough.md` 记录：

- 目标、日期、App 与系统版本、运行方式、起点和必要的登录状态说明。
- 每步实际动作、界面反馈、截图文件名；失败、空状态和未完成步骤同样记录。
- 观察事实、问题假设、关联 HCI 原则与改进建议、待真人或真机验证的事项。
- 可复现性：是否重新走过相同流程，状态差异是什么。

AX 文字用于补充控件和文本信息；视觉判断引用真实截图。记录 Mac 环境，手机专属结论附真机证据。测试记录使用参与者代号，并保留指标来源；Agent 走查与真人 Maze 数据明确区分。

## 提交前检查

共享截图裁切或遮盖与分析无关的姓名、学号、头像、账号、二维码、通知和其他私人内容，确认处理后仍能解释问题。仅提交脱敏的副本；个人原始截图、账户文件、录音和参与者身份映射放在本地 `private/`、`evidence/raw/` 或 `evidence/private/`，这些目录已被 Git 忽略。

`.gitignore` 不能自动识别敏感内容。提交前逐一查看新增文件与 diff，确保没有秘密或个人原始资料进入版本历史。
